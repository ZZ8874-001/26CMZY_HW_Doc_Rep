\section{基础部分}
\begin{enumerate}
    \item 电流检测计可以在工作电压范围内正常工作；
    \item 电流检测计总内阻小于25毫欧；
    \item 电流检测量程为100mA到6A；
    \item 电流测量误差小于20\%；
    \item 响应时间小于40ms；
    \item 充电控制电路有过流保护（过流切断输出）功能，断电超调不超过200mA，响应时间不大于40ms；
\end{enumerate}
